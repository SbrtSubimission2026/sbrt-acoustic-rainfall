# sbrt-acoustic-rainfall
Official repository containing the source code, feature extraction pipeline, and ML models for the acoustic rainfall sensing paper.

## Project Overview
This repository contains the source code, audio processing scripts, dataset builder, feature extraction pipeline, machine learning models, results visualization, and the testing notebooks used to generate the results for the paper submitted to SBrT 2026. The main goal of this codebase is to ensure the full reproducibility of our experiments.

## Repository Structure
* `data/`: Contains the `processed/`, `raw/` and `splits/` folders. The `processed/` directory holds the `.csv` files with the pre-calculated features, while `splits/` contains the metadata of the audio files used and `raw/` contains the original data.
* `notebooks/`: Contains all the testing Jupyter notebooks, organized into subfolders based on the respective testing environments (e.g., IDSM and UECE).
* `rainfall_acoustic_classification/`: The core directory containing the essential Python scripts required to run the feature extraction and classification pipelines.
* `reports/`: Directory where all the output `.csv` files and results generated by the notebooks are saved.
